# Diplom_3

1. Исправлена проверка видимости элементов Булки, Соусы, Начинки после скролла или клика по вкладке, определяется через наличие ключевого слова в классе элемента. Добавлено в x.path ancestor::div[contains(@class, 'tab_type_current')

2. Тело запроса передаем через объект, для этого созданы классы User и UserClient.

3. Все вызовы ручек вынес из тестовых классов

4. Использую BeforeEach, браузер из параметров убирал. Выбор браузера сделал через сис переменную: mvn clean test -Dbrowser=yandex - запуск тестов в Яндексе, mvn clean test -Dbrowser=chrome - запуск тестов в Chrome.

5. Везде, где создаётся пользователь, удаляется через API userClient.delete(token);
